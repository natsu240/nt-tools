Claude の新モデルリリース情報を取得し、特徴を要約するスキルだ。

## 取得元（この順で確認しろ。1つも飛ばすな）

- **Anthropic 公式モデルページ**: `https://docs.anthropic.com/en/docs/about-claude/models` を WebFetch で取得しろ
- **Anthropic 公式ブログ**: `https://www.anthropic.com/news` を WebFetch で取得し、モデルリリースに関する最新記事を探せ
- **Claude Code CHANGELOG**: `https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md` を WebFetch で取得し、新モデル対応の記述を探せ

## 引数の解釈

- 省略 → 上記ソースから最新のモデルリリース情報を探して報告しろ
- `opus 4.7` のようなモデル名指定 → そのモデルの情報を探して報告しろ

## 出力フォーマット

```
## Claude {モデル名}

**リリース日**: YYYY-MM-DD（確認できなければ「未確認」）
**モデル ID**: claude-xxx-x-x

**特徴**
- （3〜5項目。前モデルとの違いを中心に）

**前モデルとの比較**
| | {前モデル} | {新モデル} |
|---|---|---|
| 性格 | ... | ... |
| 得意なこと | ... | ... |
| 注意点 | ... | ... |

**使い分けの推奨**
- {新モデル}: （どんな場面で使うべきか）
- {前モデル}: （どんな場面でまだ使うべきか）

**CLAUDE.md / スキルへの影響**
- （プロンプトの書き方を変えるべきか、命令形の効き具合に差があるか等）

> 出典: （参照した URL）
```

## 厳守事項（1つでも破るな）

- **一次ソースのみ使え**: Anthropic 公式ドキュメント・ブログから取得した情報のみで回答しろ。記憶や訓練データだけで特徴を語るな
- **確認できない情報は「未確認」と書け**: リリース日・ベンチマーク等、ソースに記載がなければ推測するな
- **誇張するな**: 「劇的に向上」「大幅に改善」等の誇張表現は使うな。具体的な差分を書け
- **前モデルとの差分に集中しろ**: 新モデル単体の説明ではなく、前モデルと何が変わったかを中心にまとめろ
- **CLAUDE.md への影響を必ず言及しろ**: プロンプトの書き方や命令形の効き具合に差がある場合は明記しろ。ない場合は「影響なし」と書け
